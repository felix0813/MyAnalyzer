# Edge 浏览器扩展：History Recorder

## 功能
- 监听并记录浏览器历史访问记录。
- 保存每条记录的 URL、页面标题、访问时间。
- 在扩展弹窗中查看本地缓存的历史记录。
- 支持一键清空扩展内缓存的记录。

## 安装方式（Microsoft Edge）
1. 打开 `edge://extensions/`
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择当前项目中的 `extension` 文件夹。

## 说明
- 扩展依赖 `history` 权限读取浏览器历史。
- 记录保存在 `chrome.storage.local` 中，仅为扩展本地缓存。
- 首次安装时会读取最近 100 条历史记录作为初始化数据，之后持续监听新访问记录。
