# Edge 浏览器扩展：History Recorder

## 功能
- 监听并记录浏览器历史访问记录。
- 保存每条记录的 URL、页面标题、访问时间。
- 在扩展弹窗中查看最近缓存的历史记录。
- 支持配置本地 Agent 或后端接收地址，并直接通过 `POST JSON` 发送数据。
- 当接收端返回 `2xx` 成功状态时，自动删除扩展内缓存的数据。
- 支持一键清空扩展内缓存的记录。

## 安装方式（Microsoft Edge）
1. 打开 `edge://extensions/`
2. 开启“开发人员模式”。
3. 点击“加载解压缩的扩展”。
4. 选择当前项目中的 `extension` 文件夹。

## 发送数据格式
扩展会向你配置的地址发送如下 JSON：

```json
{
  "source": "edge-history-recorder",
  "sentAt": "2026-03-20T12:00:00.000Z",
  "recordCount": 2,
  "records": [
    {
      "url": "https://example.com",
      "title": "Example Domain",
      "visitedAt": "2026-03-20T11:58:00.000Z"
    }
  ]
}
```

## 使用说明
1. 在扩展弹窗中填写本地 Agent 或后端的接收地址，例如：`http://127.0.0.1:8000/api/history`
2. 点击“保存地址”保存配置。
3. 点击“发送并清空”后，扩展会把当前本地缓存的浏览记录发送到目标地址。
4. 只有当目标地址返回 HTTP `2xx` 时，扩展才会自动清空本地缓存；如果发送失败，本地数据会保留，方便重试。

## 说明
- 扩展依赖 `history` 权限读取浏览器历史。
- 记录和发送地址都保存在 `chrome.storage.local` 中。
- 首次安装时会读取最近 100 条历史记录作为初始化数据，之后持续监听新访问记录。
